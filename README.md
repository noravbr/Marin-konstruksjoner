# Marin konstruksjon – matrisebasert analyse

Dette repositoryet inneholder **en ZIP-fil** som igjen inneholder selve prosjektet.

## Innhold
- Repositoryet inneholder én ZIP-fil
- ZIP-filen inneholder et komplett prosjekt
- Kildekoden ligger **inni ZIP-filen**, ikke direkte i repositoryets filstruktur

## Om prosjektet
Prosjektet er laget som en del av faget **Objektorientert programmering** og tar for seg
beregninger innen **marin konstruksjon**.

Målet med prosjektet er å utvikle kode som benytter **matrisemetoden** for å utføre
ingeniørmessige beregninger på en **vilkårlig konstruksjon**.

## Faglig innhold
Programmet er utviklet for å kunne beregne:
- krefter i konstruksjonen
- momenter
- spenninger (stress)
- tøyninger (strekk)

Beregningene er basert på matriseoperasjoner og strukturert objektorientert design.

## Bruk av prosjektet
1. Last ned ZIP-filen fra repositoryet
2. Pakk den ut lokalt
3. Åpne prosjektet i et Java-støttet utviklingsmiljø (for eksempel IntelliJ IDEA eller Eclipse)
4. Kjør programmet derfra

## Merknad
Dette repositoryet fungerer som en **distribusjonsmappe** for prosjektet.  
All funksjonell kode ligger inne i ZIP-filen.
